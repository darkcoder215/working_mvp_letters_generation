# 🚀 GET STARTED IN 3 MINUTES

## ⬇️ Download & Extract
1. Download `arabic-job-offer-final.zip`
2. Extract to your desired folder

## 📦 Install Dependencies
Open terminal in the project folder:
```bash
npm install
```
⏱️ Takes ~30 seconds

## ▶️ Run Locally
```bash
npm run dev
```
🌐 Open browser to: http://localhost:5173

## 🐛 Troubleshooting

**Problem**: npm install fails
**Solution**: 
```bash
npm cache clean --force
npm install
```

**Problem**: Port 5173 in use
**Solution**: Vite will use next port (5174, etc.) automatically

**Problem**: PDF has corrupted Arabic
**Solution**: You shouldn't see this anymore! We fixed it with dom-to-image

**Problem**: Nothing happens when I click Download PDF
**Solution**: Check browser console (F12) for errors, make sure dom-to-image installed
