# ⚡ Quick Start Guide

Get up and running in 3 minutes!

## 1️⃣ Installation (1 minute)

\`\`\`bash
# Clone and install
git clone <repo-url>
cd figma-template-generator
npm install
\`\`\`

## 2️⃣ Setup API Key (30 seconds)

Option A: Use UI (Recommended)
- Just enter API key when using the app
- No configuration needed

Option B: Environment Variable
\`\`\`bash
echo "ANTHROPIC_API_KEY=sk-ant-your-key-here" > .env.local
\`\`\`

Get API key: https://console.anthropic.com

## 3️⃣ Run (30 seconds)

\`\`\`bash
npm run dev
\`\`\`

Open: http://localhost:3000

## 4️⃣ Test with Example (1 minute)

1. Copy code from \`examples/job-offer-example.jsx\`
2. Paste into editor
3. Enter API key
4. Click "Generate Fillable Template"
5. Wait 20-30 seconds
6. ✨ Your template is live!
